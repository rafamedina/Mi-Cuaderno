# Mi Cuaderno

Este repositorio funciona como un cuaderno digital donde se recopila la teoría y ejercicios prácticos relacionados con el acceso a datos en Java.

## Organización del repositorio

La estructura está pensada para facilitar el estudio y la consulta de los diferentes temas de la asignatura:

- **Acceso a datos**  
  Carpeta principal que agrupa los temas teóricos y prácticos del curso. Dentro encontrarás:
  - **1. Introducción a la persistencia de ficheros**  
    Subtemas como definición, fundamentos de persistencia y ejercicios adicionales.
  - **4. Acceso aleatorio a ficheros**  
    Incluye clases y ejemplos sobre acceso aleatorio, como las clases NIO.
  - **5. Ficheros Binarios y Serialización de Objetos**  
    Teoría e introducción al manejo de ficheros binarios y la serialización.
  - **6. Lectura y Escritura de Ficheros XML**  
    Explicaciones teóricas e implementación de procesamiento XML, por ejemplo, con DOM.

- **Ejercicios Github**  
  Enlace al GitHub de ejercicios.
  
- **Programas para empezar**  
 Que aplicaciones vamos a utilizar.
